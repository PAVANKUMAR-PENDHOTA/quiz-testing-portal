# Quiz Testing Portal - Frontend

This repository contains the frontend for the Quiz Testing Portal application.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

## Build

Generate a production build:

```bash
npm run build
```

## Notes

- Keep frontend code in the `src` folder.
- Update environment variables as needed in the appropriate config file.
